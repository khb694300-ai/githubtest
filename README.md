# 영어 단어장

브라우저에서 바로 여는 영어 단어 학습 페이지입니다. 설치나 서버 없이 `index.html`만 있으면 사용할 수 있습니다.

단어 72개가 들어 있고, 각 단어에는 한국어 뜻, 품사, 예문과 해석이 있습니다.

## 사용 방법

`index.html`을 브라우저로 엽니다.

위쪽 분류에서 공부할 범위를 고릅니다.

- **기초**: 처음 열면 선택되어 있는 기본 단어
- **일상**, **감정**, **여행**, **직장**, **학습**, **사회**
- **전체**: 모든 단어

학습 방식은 네 가지입니다.

| 방식 | 하는 일 |
| --- | --- |
| 카드 | 영어 단어를 보고 뜻을 확인한 뒤, 알아요 또는 몰라요로 표시합니다. |
| 퀴즈 | 뜻을 보고 단어를 고르거나, 단어를 보고 뜻을 고릅니다. |
| 받아쓰기 | 뜻을 보고 영어 철자를 입력합니다. |
| 단어장 | 단어를 검색하고, 아는 단어 표시를 바꾸거나 발음을 듣습니다. |

한 라운드는 10문제입니다. 맞힌 단어는 아는 단어로 저장되고, 틀린 단어는 다음 라운드에서 다시 나옵니다.

## 단축키

카드에서는 `Space`로 카드를 뒤집고, `←`는 몰라요, `→`는 알아요, `S`는 발음입니다. `Shift+S`는 천천히 읽습니다.

퀴즈에서는 `1`부터 `4`로 보기를 고르고, `Enter`로 다음 문제로 갑니다.

받아쓰기에서는 `Enter`로 답을 확인합니다.

## 발음

발음과 천천히 버튼은 브라우저의 영어 음성으로 단어를 읽습니다. 브라우저가 음성 합성을 지원하지 않으면 재생되지 않습니다.

## 저장

아는 단어, 오늘 맞힌 개수, 연속 학습 일수는 이 브라우저의 `localStorage`에만 저장됩니다. 하루 목표는 10개입니다. 기록 지우기를 누르면 이 브라우저의 학습 기록만 삭제됩니다.

다른 브라우저나 다른 컴퓨터의 기록과는 공유되지 않습니다.
